Hilfe

Wie können wir helfen?

Die schnellsten Antworten stehen unten. Für alles andere schreiben Sie an support@camipack.com oder eröffnen Sie ein GitHub-Issue – wir lesen beides. Fragen zum Datenschutz und Anfragen zu Ihren Daten: privacy@camipack.com.

Häufige Fragen

Wie plane ich eine Reise?

Tippen Sie auf + Neue Reise, benennen Sie sie, wählen Sie Ziel und Daten. Öffnen Sie die Reise, tippen Sie auf einen Tag und dann auf das grüne +, um Orte, Restaurants, Spaziergänge oder Tickets hinzuzufügen. In einer Aktivität setzt „Auf der Karte finden“ eine Nadel – die nummerierten Nadeln entsprechen der Reihenfolge im Zeitstrahl. Die eingebaute Hilfe (Wolken-Pille → Hilfe) enthält Schritt-für-Schritt-Anleitungen für jede Funktion.

Wie funktioniert das Teilen einer Reise?

Öffnen Sie die Reise → ⋯ → Reise teilen und schicken Sie die Einladung (am besten über Nachrichten). Sobald sie beitreten, bearbeiten Sie beide dieselbe Reise, und Änderungen gleichen sich binnen Augenblicken ab. Beide Seiten müssen bei iCloud angemeldet sein. Zum Beenden: dasselbe Menü → Teilen beenden.

Wie funktionieren Offline-Karten?

Öffnen Sie die Reise → ⋯ → Offline-Karte … → Offline-Karte laden (eine Stadt sind etwa 10–40 MB; nutzen Sie WLAN). Danach zeigt die Reisekarte selbst im Flugmodus Straßen, Beschriftungen, Ihre Nadeln und Routen. Wenn Sie den Plan später ändern, tippen Sie auf Karte aktualisieren, um den Bereich um die neuen Orte neu zu laden.

Der Sync sagt „Bei iCloud anmelden“ – was tun?

Camipack gleicht über Ihre eigene iCloud ab. Gehen Sie zu iOS-Einstellungen → Ihr Name → iCloud und stellen Sie sicher, dass iCloud für Camipack eingeschaltet ist. Ohne iCloud funktioniert die App auf einem Gerät weiterhin vollständig – es fehlen nur Abgleich und Teilen.

Änderungen an der Packliste erscheinen nicht auf einem anderen Telefon

Beide Telefone brauchen die aktuelle App-Version (ältere kennen die neueren Datensatztypen nicht). Prüfen Sie auf beiden Geräten den App Store auf Updates und ziehen Sie dann die Reiseliste nach unten, um zu aktualisieren.

Kann ich eine Reise sichern oder umziehen?

Ja – öffnen Sie die Reise → ⋯ → Reise exportieren. Dabei entsteht eine einzelne .camipack-Datei mit dem ganzen Plan und seinen Dokumenten. Wird eine solche Datei auf einem iPhone mit Camipack angetippt, bietet die App den Import an. Beachten Sie: Eine exportierte Datei ist eine unabhängige Kopie – zum gemeinsamen Planen in Echtzeit nutzen Sie stattdessen „Reise teilen“.

Kann ich Camipack in meiner Sprache lesen?

Camipack gibt es auf Englisch, Deutsch, Französisch, Italienisch, Niederländisch, Polnisch, Spanisch, Portugiesisch, Russisch und Ukrainisch. iOS lässt Sie die Sprache für eine einzelne App festlegen, ohne Ihr Telefon umzustellen: iOS-Einstellungen → Camipack → Sprache. Die App verlinkt aus ihren eigenen Einstellungen ebenfalls dorthin.

Wo liegen meine Daten? Haben Sie Zugriff darauf?

Auf Ihrem iPhone und in Ihrer eigenen iCloud. Es gibt kein Konto, und wir haben keinen Zugriff auf Ihre iCloud. Die einzige Ausnahme ist optional: Wenn Sie einen KI-Assistenten mit einer Reise verbinden, wird eine Zusammenfassung dieser Reise auf dem Server von Camipack gespeichert, damit der Assistent sie lesen kann – siehe KI-Assistenten in der Datenschutzerklärung.

KI-Assistenten

Claude: Der Code ist abgelaufen oder falsch

Ein Code funktioniert nur einmal und nur 10 Minuten lang. Tippen Sie in Camipack auf Neuer Code und geben Sie den neuen Code in Claude ein. Codes haben 8 Zeichen; prüfen Sie, ob Sie ähnlich aussehende Buchstaben und Ziffern vertauscht haben.

Claude zeigt Camipack nicht an

Fügen Sie Camipack zuerst in Claude als benutzerdefinierten Connector hinzu (auf claude.ai oder in Claude Desktop) – siehe Use Camipack with Claude (auf Englisch). Öffnen Sie dann in einem Chat + → Connectors und stellen Sie sicher, dass Camipack eingeschaltet ist.

Claude sagt, es sieht die Reise nicht

Öffnen Sie in Camipack die Reise → Teilen → Claude und stellen Sie sicher, dass das Teilen mit Claude eingeschaltet ist. Öffnen Sie Camipack dann einmal mit Internetverbindung, damit die App die neueste Version der Reise hochladen kann.

Änderungen von Claude erscheinen nicht

Öffnen Sie Camipack. Änderungen werden übernommen, wenn die App geöffnet und online ist; dann erscheinen sie sofort, mit Widerrufen. Tagespläne, die Claude vorschlägt, bleiben Entwürfe, bis Sie sie annehmen.

Ich bekomme keine Mitteilung, wenn Claude meine Reise ändert

Prüfen Sie iOS-Einstellungen → Mitteilungen → Camipack und stellen Sie sicher, dass Mitteilungen erlaubt sind. Mitteilungen kommen nur für Reisen, die mit einem Assistenten geteilt sind.

Wie trenne ich einen Assistenten oder lösche meine Daten?

In Camipack: Einstellungen → KI-Assistenten → Trennen. Um alles, was Camipack auf seinem Server speichert, auf einmal zu löschen, tippen Sie auf demselben Bildschirm auf Alles auf dem Server von Camipack löschen. Das Löschen der App allein löscht die Kopie auf dem Server nicht – nutzen Sie zuerst diese Taste oder schreiben Sie an privacy@camipack.com. Sie können Camipack auch in den Connector-Einstellungen des Assistenten entfernen.

Was kann Claude sehen?

Nur die Reisen, die Sie mit ihm teilen, und nur eine Zusammenfassung: Daten, Orte, Zeiten, Gegenden, Öffnungszeiten, Reise- und Unterkunftsdetails, Dokumenttitel und Notizen, aus denen Namen, Telefonnummern, E-Mail-Adressen, Links und Codes entfernt sind. Namen der Reisenden, Straßenadressen, Tagesnotizen, Budget und Packliste werden nur gesendet, wenn Sie sie einschalten. Kartenkoordinaten, Buchungscodes, Dateien und Telefonnummern werden nie gesendet. Die vollständige Liste steht in der Datenschutzerklärung.

Kann ich stattdessen ChatGPT nutzen?

Am Computer ja: ChatGPT kann sich auf chatgpt.com als Plugin verbinden, je nachdem, welches ChatGPT-Abo Sie haben. In der ChatGPT-App auf dem Telefon funktioniert es nicht. Siehe Use Camipack with ChatGPT (computer) (auf Englisch).

Ein Problem melden

Schreiben Sie an support@camipack.com, was Sie getan haben, was Sie erwartet haben und was stattdessen passiert ist – ein Screenshot hilft enorm. Für Fragen zum Datenschutz oder um Ihre Daten löschen zu lassen, schreiben Sie an privacy@camipack.com.
