Aide

Comment pouvons-nous aider ?

Les réponses les plus rapides sont ci-dessous. Pour tout le reste, écrivez à support@camipack.com ou ouvrez un ticket GitHub — nous lisons les deux. Questions de confidentialité et demandes concernant vos données : privacy@camipack.com.

Questions fréquentes

Comment planifier un voyage ?

Touchez + Nouveau voyage, nommez-le, choisissez la destination et les dates. Ouvrez le voyage, touchez un jour, puis touchez le + vert pour ajouter des lieux, des restaurants, des promenades ou des billets. Dans une activité, « Trouver sur la carte » y place une épingle — les épingles numérotées suivent l’ordre de votre chronologie. L’Aide intégrée (pastille nuage → Aide) contient des guides pas à pas pour chaque fonction.

Comment fonctionne le partage d’un voyage ?

Ouvrez le voyage → ⋯ → Partager le voyage, puis envoyez l'invitation (Messages fonctionne le mieux). Une fois la personne arrivée, vous modifiez tous deux le même voyage et les changements se synchronisent en quelques instants. Les deux côtés doivent être connectés à iCloud. Pour arrêter : même menu → Arrêter le partage.

Comment fonctionnent les cartes hors ligne ?

Ouvrez le voyage → ⋯ → Carte hors ligne… → Télécharger la carte hors ligne (une ville pèse environ 10–40 Mo ; utilisez le Wi-Fi). Ensuite, même en mode Avion, la carte du voyage affiche les rues, les libellés, vos épingles et vos itinéraires. Si vous changez le plan par la suite, touchez Mettre la carte à jour pour retélécharger autour des nouveaux lieux.

La synchronisation dit « Connectez-vous à iCloud » – que faire ?

Camipack se synchronise via votre propre iCloud. Allez dans Réglages iOS → votre nom → iCloud et vérifiez qu’iCloud est activé pour Camipack. Sans cela, l’application fonctionne toujours entièrement sur un appareil — vous perdez seulement la synchronisation et le partage.

Les changements de liste de bagages n'apparaissent pas sur un autre téléphone

Les deux téléphones ont besoin de la version actuelle de l'app (les anciennes ne connaissent pas les nouveaux types d'enregistrement). Vérifiez les mises à jour sur l'App Store des deux appareils, puis tirez la liste des voyages vers le bas pour actualiser.

Puis-je sauvegarder ou déplacer un voyage ?

Oui — ouvrez le voyage → ⋯ → Exporter le voyage. Cela crée un seul fichier .camipack contenant tout le plan et ses documents. Toucher un tel fichier sur n’importe quel iPhone équipé de Camipack propose de l’importer. À noter : un fichier exporté est une copie indépendante — pour préparer un voyage à plusieurs en direct, utilisez plutôt Partager le voyage.

Puis-je lire Camipack dans ma langue ?

Camipack existe en anglais, allemand, français, italien, néerlandais, polonais, espagnol, portugais, russe et ukrainien. iOS vous laisse choisir la langue d’une seule application sans changer celle du téléphone : Réglages iOS → Camipack → Langue. L’application y renvoie aussi depuis ses propres réglages.

Où sont stockées mes données ? Y avez-vous accès ?

Sur votre iPhone et dans votre propre iCloud. Il n’y a pas de compte, et nous n’avons pas accès à votre iCloud. La seule exception est facultative : si vous connectez un assistant IA à un voyage, un résumé de ce voyage est conservé sur le serveur de Camipack pour que l’assistant puisse le lire — voir Assistants IA dans la politique de confidentialité.

Assistants IA

Claude : le code a expiré ou est incorrect

Un code ne fonctionne qu’une fois et seulement pendant 10 minutes. Dans Camipack, touchez Nouveau code et saisissez le nouveau code dans Claude. Les codes font 8 caractères ; vérifiez que vous n’avez pas confondu des lettres et des chiffres qui se ressemblent.

Claude n’affiche pas Camipack

Ajoutez d’abord Camipack comme connecteur personnalisé dans Claude (sur claude.ai ou dans Claude Desktop) — voir Use Camipack with Claude (en anglais). Puis, dans une conversation, ouvrez + → Connectors et vérifiez que Camipack est activé.

Claude dit qu’il ne voit pas le voyage

Dans Camipack, ouvrez le voyage → Partager → Claude et vérifiez que le partage avec Claude est activé. Ouvrez ensuite Camipack une fois en étant en ligne, pour qu’il puisse envoyer la dernière version du voyage.

Les modifications de Claude n’apparaissent pas

Ouvrez Camipack. Les modifications sont récupérées lorsque l’app est ouverte et en ligne ; elles apparaissent alors immédiatement, avec Annuler. Les programmes de journée proposés par Claude restent des brouillons tant que vous ne les avez pas acceptés.

Je ne reçois pas de notification quand Claude modifie mon voyage

Vérifiez Réglages iOS → Notifications → Camipack et assurez-vous que les notifications sont autorisées. Les notifications ne concernent que les voyages partagés avec un assistant.

Comment déconnecter un assistant ou supprimer mes données ?

Dans Camipack : Réglages → Assistants IA → Déconnecter. Pour supprimer d’un coup tout ce que Camipack conserve sur son serveur, touchez Tout supprimer sur le serveur de Camipack sur le même écran. Supprimer seulement l’app ne supprime pas la copie sur le serveur — utilisez d’abord ce bouton, ou écrivez à privacy@camipack.com. Vous pouvez aussi retirer Camipack dans les réglages de connecteurs de l’assistant.

Que peut voir Claude ?

Uniquement les voyages que vous partagez avec lui, et seulement un résumé : dates, lieux, horaires, quartiers, heures d’ouverture, détails des trajets et des hébergements, intitulés des documents et notes dont on a retiré les noms, numéros de téléphone, e-mails, liens et codes. Les noms des voyageurs, adresses postales, notes des journées, budget et bagages ne sont envoyés que si vous les activez. Les coordonnées géographiques, codes de réservation, fichiers et numéros de téléphone ne sont jamais envoyés. La liste complète figure dans la politique de confidentialité.

Puis-je utiliser ChatGPT à la place ?

Sur ordinateur, oui : ChatGPT peut se connecter comme plugin sur chatgpt.com, selon votre formule ChatGPT. Cela ne fonctionne pas dans l’app ChatGPT sur téléphone. Voir Use Camipack with ChatGPT (computer) (en anglais).

Signaler un problème

Écrivez à support@camipack.com en indiquant ce que vous avez fait, ce que vous attendiez et ce qui s’est produit à la place — une capture d’écran aide énormément. Pour toute question de confidentialité ou pour faire supprimer vos données, écrivez à privacy@camipack.com.
