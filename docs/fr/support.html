Comment pouvons-nous aider ?

Les réponses les plus rapides sont ci-dessous. Pour tout le reste, écrivez à muzyukins@gmail.com or ouvrez un ticket GitHub — nous lisons les deux.

Questions fréquentes

Comment planifier un voyage ?

Tap + Nouveau voyage, nommez-le, choisissez la destination et les dates. Ouvrez le voyage, touchez un jour, puis touchez le + vert pour ajouter des lieux, des restaurants, des promenades ou des billets. Dans une activité, « Trouver sur la carte » y place une épingle — les épingles numérotées suivent l’ordre de votre chronologie. L’ Aide intégrée (pastille nuage → Aide) contient des guides pas à pas pour chaque fonction.

Comment fonctionne le partage en famille ?

Ouvrez le voyage → ⋯ → Partager le voyage, puis envoyez l'invitation (Messages fonctionne le mieux). Une fois la personne arrivée, vous modifiez tous deux le même voyage et les changements se synchronisent en quelques instants. Les deux côtés doivent être connectés à iCloud. Pour arrêter : même menu → Arrêter le partage.

Comment fonctionnent les cartes hors ligne ?

Ouvrez le voyage → ⋯ → Carte hors ligne… → Télécharger la carte hors ligne (une ville pèse environ 10–40 Mo ; utilisez le Wi-Fi). Ensuite, même en mode Avion, la carte du voyage affiche les rues, les libellés, vos épingles et vos itinéraires. Si vous changez le plan par la suite, touchez Mettre la carte à jour pour retélécharger autour des nouveaux lieux.

La synchronisation dit « Connectez-vous à iCloud » – que faire ?

Camipack se synchronise via votre propre iCloud. Allez dans Réglages iOS → votre nom → iCloud et vérifiez qu’iCloud est activé pour Camipack. Sans cela, l’application fonctionne toujours entièrement sur un appareil — vous perdez seulement la synchronisation et le partage.

Les changements de liste de bagages n'apparaissent pas sur le téléphone de ma famille

Les deux téléphones ont besoin de la version actuelle de l'app (les anciennes ne connaissent pas les nouveaux types d'enregistrement). Vérifiez les mises à jour sur l'App Store des deux appareils, puis tirez la liste des voyages vers le bas pour actualiser.

Puis-je sauvegarder ou déplacer un voyage ?

Oui — ouvrez le voyage → ⋯ → Exporter le voyage. Cela crée un seul fichier .camipack contenant tout le plan et ses documents. Toucher un tel fichier sur n’importe quel iPhone équipé de Camipack propose de l’importer. À noter : un fichier exporté est une copie indépendante — pour préparer un voyage à plusieurs en direct, utilisez plutôt Partager le voyage.

Puis-je lire Camipack dans ma langue ?

Camipack existe en anglais, allemand, français, polonais, espagnol, portugais et russe. iOS vous laisse choisir la langue d’une seule application sans changer celle du téléphone : Réglages iOS → Camipack → Langue. L’application y renvoie aussi depuis ses propres réglages.

Où sont stockées mes données ? Y avez-vous accès ?

Sur votre iPhone et dans votre propre iCloud. Nous n’avons ni serveurs ni accès — voyez la politique de confidentialité.
